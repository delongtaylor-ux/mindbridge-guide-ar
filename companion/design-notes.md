# Companion visual specification

Source concept: generated_images/exec-a3c90c91-89b3-4795-b0fc-3aa8c1956882.png. Selected autonomously for the authorized build; not represented as user-approved.

The full primary screen uses warm ivory (#f6f3ea), forest text (#183e35), a sage lesson mat (#dfe6d8), thin gray-green rules, 8px corners, Georgia headings, and system sans-serif controls. Header, large title, three lesson tabs, 65/35 workspace, then learning notes. Mobile stacks the workspace in the same order. Buttons have at least 44px touch targets and a visible focus ring.

Visible concept copy is retained. Functional additions: lesson-state text, exact total/target, removable piece list, check feedback, challenge navigation, observation explanation, correction controls, export, and device-storage status. These support the user's requested tracking and independent challenge flows. They are not additional marketing claims.

Intentional deviations: exact SVG sectors instead of generated fraction art (mathematical accuracy); no eight-spoke empty circle because halves/thirds/quarters do not share eighth divisions; demonstration in a distinct labeled area so it cannot alter a learner's answer; guidance text varies by lesson; observation controls prevent recording guided practice as independent evidence; mobile content stacks; no remote fonts, images, analytics, AI service, or network dependency.

UI consists of semantic native controls, not a concept screenshot. The downloadable HTML is bundled from the same tested modules. Persistence is browser-local, bounded to 200 observations, without names or accounts. Export is an explicit user action. No cross-device or MindBridge backend sync exists.
